# Evaluación Unidad 4 - CRUD de taller mecánico

Entrega completa con POO, SOLID, Tkinter, MySQL, pytest, excepciones personalizadas y debugging con pdb.

## Inicio rápido

1. Importa `CRUD/db_taller.sql` en phpMyAdmin.
2. Abre una terminal dentro de esta carpeta.
3. Ejecuta `python -m pip install -r requirements.txt`.
4. Ejecuta `python -m CRUD.main`.
5. Para las pruebas, ejecuta `python -m pytest -v`.

Lee los README de cada carpeta para preparar las evidencias.

## Subirlo a Git

Después de comprobarlo en tu computadora, abre una terminal dentro de esta carpeta y ejecuta:

```bash
git init
git add .
git commit -m "Crea estructura inicial del proyecto CRUD"
```

Para demostrar varios commits, realiza y comprueba cada parte por separado antes de subirla. No inventes evidencias: las capturas deben mostrar la ejecución real en tu computadora.
