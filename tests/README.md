# Pruebas unitarias

Desde la carpeta `Evaluacion_U4`, instala las dependencias y ejecuta:

```bash
python -m pytest -v
```

Las pruebas siguen AAA: preparan datos (Arrange), ejecutan una función (Act) y verifican su resultado (Assert). También cumplen F.I.R.S.T. porque son rápidas, independientes, repetibles y se validan automáticamente. Se usa un repositorio falso para evitar modificar MySQL.
